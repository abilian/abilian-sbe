# Développeurs

Abilian SBE est une application web écrite en Python, avec Flask et SQLAlchemy. Son code est libre et ouvert aux contributions.

La documentation destinée aux développeurs suit le code de près et n'existe qu'en anglais : l'installation d'un environnement de développement, l'organisation du code, les tests, la manière de contribuer, la gouvernance du projet et la feuille de route.

[Developer guide](/en/develop/), en anglais, est le point de départ.

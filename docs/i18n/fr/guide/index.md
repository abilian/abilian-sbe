# Premiers pas

Abilian SBE s'organise autour de **communautés**. Une communauté est un espace partagé pour une équipe, un projet ou un groupe de travail, avec ses propres discussions, documents, wiki et agenda. Vous voyez les communautés dont vous êtes membre ; leurs animateurs invitent les nouveaux membres.

## Se connecter

Vous vous connectez avec votre adresse e-mail et votre mot de passe. Si vous avez été invité, l'e-mail d'invitation contient un lien pour choisir votre mot de passe. Ce lien reste valable 24 heures ; *Mot de passe oublié?*, sur la page de connexion, en envoie un nouveau.

![La page de connexion.](../assets/shots/fr/login.png)

## Mon fil

*Mon fil* est la page d'accueil. Il liste ce qui s'est passé dans toutes vos communautés, du plus récent au plus ancien : discussions lancées et réponses, documents déposés, pages de wiki écrites, événements annoncés.

![Mon fil, avec les nouveautés depuis la dernière visite, les communautés et les événements à venir.](../assets/shots/fr/home.png)

- **Nouveau** signale ce qui est arrivé depuis votre dernier clic sur *Tout marquer comme lu*. Les communautés, à droite, indiquent combien de nouveautés chacune contient.
- Les filtres au-dessus du fil ne gardent qu'un type de nouvelles : discussions, documents, agenda ou wiki.
- La zone en haut lance une discussion dans l'une de vos communautés.
- *À venir* liste les prochains événements de vos communautés.

## La barre

La barre en haut de chaque page vous mène partout :

- **Mon fil**, la page d'accueil.
- **Communautés**, un menu de vos communautés, celles qui ont du nouveau en premier, avec un filtre pour les autres et les communautés que vous pourriez rejoindre.
- **Annuaire**, les personnes avec qui vous travaillez.
- **Rechercher**, qui suggère des résultats pendant la saisie. Appuyez sur `/` depuis n'importe quelle page pour y accéder.
- **Créer**, pour lancer une discussion dans l'une de vos communautés.
- Le bouton lune ou soleil bascule entre le thème clair et le thème sombre ; vos initiales ouvrent votre compte.
